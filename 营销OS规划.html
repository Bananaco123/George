Future Roadmap

V2.0 规划

在 V1.0 已完成基础协同、AI 能力与多维看板的基础上，V2.0 聚焦经营决策、全周期治理和组织能力资产化。

V2.0

经营智能与组织能力资产化

从“业务可执行、数据可查看”升级到“经营可诊断、项目可预测、经验可复用、人才可复制”。

面向角色集团管理者、部门负责人、销售 PM、运营与一线销售
核心场景跨层经营决策、项目全周期治理、优秀经验复用与培训实战
解决问题基础数据已经可见，但跨层洞察与预测不足；项目过程与经营结果未完全贯通；优秀经验难以标准化复制，新人成长依赖人工带教。
核心模块经营决策驾驶舱、全周期项目经营、数字资产与 Skills 生态、培训实战
价值闭环业务数据沉淀 → 项目经营诊断 → 经验提炼为 Skill → 组织复用与培训 → 管理决策

经营决策驾驶舱

将 V1.0 的多维看板升级为可下钻、可诊断、可预测的经营决策入口。

  • 集团、部门、人员与项目多层视角
  • 营收结构、转化效率和增长趋势分析
  • 异常预警、原因诊断与经营复盘

全周期项目经营

贯通商机、报价、订单、交付与售后，让项目过程和经营结果形成闭环。

  • 项目节点、成本、进度与风险管理
  • 卡点诊断、责任定位与推进建议
  • 项目利润、投入产出与全周期复盘

数字资产与 Skills 生态

把销冠方法、业务规则和优秀实践沉淀为可管理、可复用的组织数字资产。

  • 业务经验制作成 Skill 并应用到 Agent
  • Skills 广场分发、版本管理与权限控制
  • 使用效果度量与 Token 激励机制

培训实战

用真实业务案例和多模态交互降低新人培养成本，持续复制组织能力。

  • 正向案例与流失案例结构化沉淀
  • 对话式、情景式和多模态实战训练
  • 能力评估、训练反馈与课程资产输出
